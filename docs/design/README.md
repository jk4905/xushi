## 视觉方向

让这一餐、当前菜和原文成为主角。保留温暖的家庭料理感，用留白、分组和简洁控件组织任务；不以装饰卡片、额外步骤或按钮制造进度。

| 元素 | 已选方向 / 当前依据 |
|---|---|
| 深绿 `#173D2B` | 主文字、主要操作和选中对比 |
| 浅绿 `#EAF0D9` | 页面底色 |
| 纸色 `#F3F6E8` | 卡片和导航表面 |
| 嫩黄绿 `#E2ED9C` | 当前选中、状态反馈；不用于大段正文 |
| 次要字色 `#52664B`、分隔 `#C5CFB2` | 辅助说明与安静边界 |
| 字体 | 系统中文字体 / 苹方优先，正文保留清楚行高 |
| 插图 | 菜品与动作示意；完整原文优先，不以图片替代未知用量或缺失做法 |
| 画幅 | 原设计 390 × 844；保存 1× 和 3× PNG，可放大查看 |

当前样式源：[H5 CSS](../../h5/weekend-menu-c.css)、[小程序全局 WXSS](../../miniprogram/app.wxss)。图稿中的正文 17px、做法 18px、主操作 52px 是当时设计数值；当前平台样式存在差异，例如小程序通用按钮最小高度48px。不能仅凭图稿宣称实际触控尺寸已验收，也不因文档归档擅自改现有 UI。

## 画面组织与操作层级

| 场景 | 视觉主角 | 操作原则 |
|---|---|---|
| 首页 | 当前餐、阶段、继续入口；空状态说明用途 | 安排或继续为首要操作，不重复展示常做菜单库 |
| 选菜 | 搜索、已选菜品、常做菜单 | 保存成功才创建一餐；链接录入是就地分支 |
| 买菜 | 食材名称、原始用量、已备齐状态 | 整行可直接勾选 / 取消，原位反馈不抢滚动 |
| 下厨 | 餐名、完整菜名切换、原文与插图 | 阅读连续滚动；不加上一步、下一步或总览关卡 |
| 编辑 / 本餐调整 | 当前输入、失败原因、底部保存 | 区分保存修改与完成整餐；成功返回，失败保留输入 |
| 完成 / 取消 | 被操作的餐名、结果和可退出动作 | 业务状态在明确确认且保存成功后改变 |

## 图稿不能直接覆盖实现的差异

| 图稿内容 | 当前处理 / 开发提醒 |
|---|---|
| 首页四阶段条、示例“上次看到”卡 | 用户后续要求去掉未串联流程的首页元素；当前首页已精简。保留餐次状态和继续入口，不按旧稿恢复阶段条。 |
| 大块深绿标题区、旧图标和按钮位置 | C 配色方向延续，但两端已有布局微调。图稿是视觉参考，不是要求本轮逐像素回滚。 |
| `11-step`、`12-next` 等文件名 | 是同一长文的滚动快照；没有步骤确认页面或“下一步”按钮。 |
| 编辑页仍显示 Tab | 当前小程序的选菜 / 菜谱编辑 / 本餐调整等表单页聚焦返回与保存，不照图强加 Tab。H5规则见交互规格。 |
| “保存并返回 / 取消不提交”的统一表述 | H5本餐调整当前逐项自动保存，退出不撤销；小程序先留草稿再点完成提交。旧图不能证明两端都具备同一种取消语义。 |
| 两个 Tab 都恢复完整页面栈 | H5有自己的栈恢复；小程序原生切 Tab 先进入根页，再由继续入口恢复餐次。两者不能混为同一种实现。 |
| 做法按段落锚点恢复 | H5与微信当前实现不同，小程序主要保存像素滚动位置；改正文或新增上方内容后的精确锚点恢复不能视为已解决。 |
| 链接录入、完成和失败的底部浮层 | 小程序使用平台页面 / 对话框等容器；保存结果和恢复行为应一致，容器无需照搬静态图。 |
| 完成后去“做过”列表 | 两端实际成功去向有差异，按交互规格核对；不能凭图宣称已统一。 |
| “打开原链接” | H5可打开外链；小程序复制链接后查看，不等于内置解析。 |
| 背景里的16 / 19项、周末晚餐与三道菜 | 仅为示例数据；实际名称、数量、材料完整度和菜品由用户记录决定。 |
| 首次打开的空状态图 | 当前自用试用包首次无记录时携带 3 道菜谱与 2 个旧测试餐次，直接显示“今晚这餐”；空状态仍用于主动清空后的库。此轮仅调整初始数据，不改布局、样式和动效。 |

## 动效与无障碍检查边界

动效表达状态连续性，不延迟导航或保存，不让清单行重排。当前微信 Tab 的底色滑动配置为240ms，代码在 [app-tabs](../../miniprogram/components/app-tabs/index.wxss)；静态图不能证明动画中间帧、帧率或手感。

触控区、中文换行、长菜名、长段落、底部栏与键盘、放大字号、VoiceOver、减少动态效果必须分别实测。已有代码保护不等于真机通过；后续检查按 [验收脚本](../../miniprogram/ACCEPTANCE.md) 记录，不把设计图当使用证据。
